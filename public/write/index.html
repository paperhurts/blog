Posts go straight to your blog's repository on GitHub. The token stays on this device.

How to make a token
  1. Open new fine-grained token on GitHub.
  2. Under Repository access, choose Only select repositories and pick the blog's repo.
  3. Under Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Pick an expiration, generate it, and paste it above.
